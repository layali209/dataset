Resume Parsing Project

Python + OCR + NLP + Database | All phases summarized

Phase 1: Resume Text Extraction

Objective:

Extract text from resumes in PDF or image format using OCR.

  • Installed Tesseract OCR for text extraction.
  • Converted PDF resumes to images using Poppler.
  • Extracted raw text using Python's pytesseract library.
  • Saved extracted text to a file for further processing.

Phase 2: Data Cleaning & Normalization

Objective:

Clean extracted text and remove noise for accurate processing.

  • Removed unwanted characters and extra spaces.
  • Normalized formatting for dates, phone numbers, and other entities.
  • Tokenized text and applied basic normalization using Python.

Phase 3: Named Entity Recognition (NER)

Objective:

Identify important entities like Name, Skills, Education, and Experience.

  • Used SpaCy to implement NER.
  • Trained custom NER models with labeled resume data.
  • Evaluated model using precision, recall, and F1-score.

Phase 4: Relationship Extraction

Objective:

Associate entities to establish meaningful relationships.

  • Linked each person to their education, skills, and experiences.
  • Used rule-based parsing and sentence-level analysis.
  • Stored relationships in a structured format for analysis.

Phase 5: Database & Analysis

Objective:

Store parsed resume data in a structured database for querying and analysis.

  • Designed database schema for Persons, Education, Skills, and Experience.
  • Inserted extracted entities and relationships into SQLite database.
  • Queried database to retrieve meaningful insights.
  • Prepared data for machine learning models to predict trends or analyze skills.
